# クラシック公演ポータル

N響・都響・東響の公演情報と、おけぴ掲示板の譲渡チケットを1画面で見るための個人用ツール。

## 起動

```bash
python3 server.py
```

ブラウザで http://localhost:8765 が開きます（終了は Ctrl+C）。
画面右上の「最新に更新」で各サイトから取り直します（1〜2分）。

## ファイル

- `scraper.py` … 各サイトを取得して `data/concerts.json` を作る。単体でも `python3 scraper.py` で実行可
- `server.py` … 画面の表示と「最新に更新」ボタン用のローカルサーバー
- `sales.py` … 発売日（1回券・定期会員券）とチケット関連ニュースを取得（scraper.py から呼ばれる）
- `index.html` … ポータル画面

## 取得元

| サイト | 取得方法 |
| --- | --- |
| N響 | 公式サイトが画面表示に使っている JSON（`/concert/json/archive_concert_YYYY.json`） |
| 都響 | 公演一覧ページ `/j/concert/` の HTML |
| 東響 | 公演一覧ページ `/concert/` の HTML |
| おけぴ | 掲示板を「N響」「NHK交響楽団」「都響」「東京都交響楽団」「東響」「東京交響楽団」でキーワード検索（各3ページまで） |

発売日は、N響は1回券・シーズン会員券・年間会員券の各ページ、都響・東響は各公演ページの発売日欄から取得します。
公演ページは件数が多いので、一度読んだら1週間は `data/sales_cache.json` の内容を使います。

おけぴの投稿は「楽団」と「公演日（・開演時刻）」が一致する公式公演に紐付けます。
各サイトの HTML 構成が変わると取得できなくなるので、その場合は `scraper.py` の該当関数を直してください。
アクセスは1リクエストごとに1秒空けています。個人利用の範囲で使ってください。

## 備考

- ★（行きたい）と絞り込み条件はブラウザに保存されます
- 「土日祝」は土日のみで判定しています（祝日データは持っていません）
